## Por qué se usa el starter

Mi equipo (My-Academic-Space) tiene el repositorio de documentación (mas-docs), pero todavía no tiene un repositorio de código con la app funcionando, así que no había una app del equipo para copiar como línea base.

Por eso uso el starter del curso (Ionic React + API Express), en la versión con mi trabajo del parcial C2: un catálogo de productos con lista, detalle y formulario. Usa la misma tecnología que usará la app del equipo, así que las mejoras de este taller (estados de carga, tokens, accesibilidad, formulario) se pueden llevar después a My-Academic-Space.

El trabajo de este taller es individual: los cambios, las capturas y los documentos de esta carpeta son míos.
