# Backlog ágil - App de horario para estudiantes

## 1. Historias de usuario

### Historia 1 - Ver horario

**Como estudiante, quiero ver mi horario de clases para saber qué materias tengo durante la semana.**

**Criterios de aceptación:**

* Poder ver los días, materias, horas y salones.
* El horario debe mostrarse de forma ordenada y fácil de entender.

**Prioridad:** Imprescindible

### Historia 2 - Agregar una materia

**Como estudiante, quiero agregar una materia a mi horario para tener todas mis clases organizadas.**

**Criterios de aceptación:**

* Poder escribir el nombre de la materia, la hora y el salón.
* La materia debe aparecer en el horario después de guardarla.

**Prioridad:** Imprescindible

### Historia 3 - Recordatorios

**Como estudiante, quiero recibir un recordatorio antes de una clase para no olvidar la hora de inicio.**

**Criterios de aceptación:**

* Recibir una notificación antes de que empiece la clase.
* El recordatorio debe mostrar la materia y la hora.

**Prioridad:** Imprescindible

### Historia 4 - Tomar notas

**Como estudiante, quiero escribir notas por materia para guardar información importante de las clases.**

**Criterios de aceptación:**

* Poder escribir una nota y relacionarla con una materia.
* Poder ver la nota después de haberla guardado.

**Prioridad:** Imprescindible

### Historia 5 - Editar horario

**Como estudiante, quiero modificar una materia de mi horario para corregir cambios de hora o salón.**

**Criterios de aceptación:**

* Poder cambiar el nombre, la hora o el salón de una materia.
* Los cambios deben quedar guardados en el horario.

**Prioridad:** Deseable

### Historia 6 - Eliminar una materia

**Como estudiante, quiero eliminar una materia del horario para quitar las clases que ya no tengo.**

**Criterios de aceptación:**

* Poder seleccionar una materia y eliminarla.
* La materia eliminada ya no debe aparecer en el horario.

**Prioridad:** Deseable
