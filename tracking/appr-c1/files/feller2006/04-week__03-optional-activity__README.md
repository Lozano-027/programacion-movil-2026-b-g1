# SHOPPING LIST

### 1. APP IDEA

### PROBLEM

A veces las personas olvidan los productos que necesitan comprar o no tienen una lista organizada. Esto puede hacer que compren cosas que no necesitan y olviden otras importantes.

### TARGET USERS

La aplicación está dirigida principalmente a personas que quieren organizar sus compras de una manera sencilla. Puede ser útil para estudiantes, familias y cualquier persona que haga compras regularmente.

### MVP

La primera versión de la aplicación tendrá tres funciones principales:

1. Agregar productos a la lista de compras.
2. Ver los productos que están en la lista.
3. Marcar los productos como comprados.

## 2. User Stories and Backlog

### HU01 - Agregar productos

**Historia de usuario:**  
Como usuario, quiero agregar productos a mi lista de compras para recordar qué necesito comprar.

**Criterios de aceptación:**
- El usuario puede escribir el nombre de un producto.
- El usuario puede agregar el producto a la lista.
- El producto aparece en la lista después de agregarlo.

### HU02 - Ver productos

**Historia de usuario:**  
Como usuario, quiero ver los productos de mi lista para saber qué necesito comprar.

**Criterios de aceptación:**
- El usuario puede ver todos los productos agregados.
- Los productos aparecen en una lista.
- La lista se actualiza cuando se agrega un nuevo producto.

### HU03 - Marcar productos como comprados

**Historia de usuario:**  
Como usuario, quiero marcar un producto como comprado para saber qué productos ya compré.

**Criterios de aceptación:**
- El usuario puede marcar un producto como comprado.
- El producto se identifica como comprado en la lista.
- El usuario puede diferenciar los productos comprados de los que todavía están pendientes.

### HU04 - Eliminar productos

**Historia de usuario:**  
Como usuario, quiero eliminar productos de mi lista para quitar los productos que ya no necesito comprar.

**Criterios de aceptación:**
- El usuario puede seleccionar un producto de la lista.
- El usuario puede eliminar el producto.
- El producto eliminado ya no aparece en la lista.

### HU05 - Editar productos

**Historia de usuario:**  
Como usuario, quiero editar un producto de mi lista para corregir o cambiar su nombre.

**Criterios de aceptación:**
- El usuario puede seleccionar un producto de la lista.
- El usuario puede cambiar el nombre del producto.
- El producto aparece actualizado después de guardar el cambio.

### HU06 - Buscar productos

**Historia de usuario:**  
Como usuario, quiero buscar un producto en mi lista para encontrarlo más fácilmente.

**Criterios de aceptación:**
- El usuario puede escribir el nombre del producto que quiere buscar.
- La aplicación muestra los productos que coinciden con la búsqueda.
- Si no encuentra el producto, muestra que no hay resultados.

## 4. App type and methodology

### App type

Se eligió una aplicación móvil nativa porque la lista de compras se puede utilizar fácilmente desde un celular. Además, las personas normalmente llevan su teléfono cuando van a realizar sus compras, por lo que pueden verificar la lista en cualquier momento.

### Methodology

Se eligió la metodología Scrum porque permite organizar el proyecto en diferentes sprints. En cada sprint se pueden desarrollar algunas funciones de la aplicación y revisar el avance antes de continuar con las siguientes. Para este proyecto, Scrum permite trabajar primero en las funciones principales y después agregar otras funciones.

## Project pitch

Shopping List is a mobile app that helps people organize their shopping list. Sometimes people forget the products they need to buy or do not have an organized list. The target users are students, families, and people who go shopping regularly. The MVP allows users to add products, see their shopping list, and mark products as purchased. This app can help users organize their purchases and remember the products they need.
