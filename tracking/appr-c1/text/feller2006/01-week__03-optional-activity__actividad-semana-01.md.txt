# Actividad Semana 01 — Analiza apps y define un MVP

##  Análisis de 3 aplicaciones

Para esta actividad seleccioné tres aplicaciones que utilizo con frecuencia: WhatsApp, Instagram y Spotify. Analicé el tipo de aplicación y las funciones principales que considero necesarias para formar su MVP.

| Aplicación | Tipo probable | Funciones principales del MVP                            |
| ---------- | ------------- | -------------------------------------------------------- |
| WhatsApp   | Nativa        | Enviar mensajes, enviar imágenes y realizar llamadas     |
| Instagram  | Nativa        | Ver publicaciones, crear publicaciones y seguir usuarios |
| Spotify    | Nativa        | Buscar canciones, reproducir música y crear playlists    |

### WhatsApp

Considero que WhatsApp es una aplicación nativa porque está diseñada específicamente para dispositivos móviles y utiliza diferentes funciones del teléfono. Para su MVP considero indispensables enviar mensajes, compartir imágenes y realizar llamadas.

### Instagram

Considero que Instagram es una aplicación nativa porque está diseñada para funcionar en dispositivos móviles y aprovecha características propias de estos. Para su MVP considero indispensables ver publicaciones, crear publicaciones y seguir usuarios.

### Spotify

Considero que Spotify es una aplicación nativa porque cuenta con aplicaciones específicas para dispositivos móviles y está diseñada para ofrecer una experiencia de reproducción de música. Para su MVP considero indispensables buscar canciones, reproducir música y crear playlists.

##  Idea de mi aplicación

Mi idea es desarrollar una aplicación móvil para llevar el control de asistencia de los estudiantes a sus clases.

### Problema

Actualmente, llevar el control de la asistencia puede hacerse de forma manual y puede ser difícil saber cuántas clases se han asistido o cuántas faltan. La aplicación busca facilitar este proceso y permitir que el estudiante tenga la información organizada en un solo lugar.

### Público objetivo

La aplicación está dirigida principalmente a estudiantes universitarios que quieran llevar un control sencillo de su asistencia a las diferentes clases que tienen durante el semestre.

### Funciones principales del MVP

1. Registrar la asistencia a una clase.
2. Consultar el historial de asistencias.
3. Ver el porcentaje de asistencia de cada materia.

##  Tecnología elegida

Para desarrollar la aplicación utilizaría Flutter, ya que permite crear aplicaciones móviles para diferentes sistemas operativos utilizando un mismo proyecto. Esto facilitaría el desarrollo y permitiría tener una aplicación para Android y también para iOS.

Elegiría Flutter porque es una tecnología que permite crear interfaces de forma sencilla y organizar el proyecto de manera clara. Además, sería adecuada para desarrollar las funciones principales de la aplicación, como registrar asistencias, consultar el historial y mostrar el porcentaje de asistencia.
